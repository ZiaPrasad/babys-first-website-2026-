# Kiki's Loom Room ✦

A cozy, interactive portfolio for **Kiki**, an original character (Moon-Mouseling, Apprentice Starlight Weaver).
Built for the haX.baby "Baby's First Portfolio" hackathon, **Track 2 (original character)**, aiming at Tier 3.

No build step, no dependencies: plain HTML, CSS and JS. Open `index.html` or run `python3 -m http.server`.

## Features
- Character sheet (name, what, does, story, tagline), scroll-driven 5-scene story
- Cursor/touch reaction, day/night mood toggle (changes art + palette), hidden scarf Easter egg (3 clicks)
- 3 playable projects: Blanket Loom, Connect-the-Dots, Star-Tea Steeper
- **Tier 3:** Kiki remembers visitors (localStorage), chats back (rule-based "Kiki Messenger"), no-dependency fast page
- Side quests: sparkle cursor trail, click sounds + mute toggle (Web Audio synth), threads odometer, draggable yarn toy

## Credits
Kiki artwork + animation clips are AI-generated (image generation + Magic Hour image-to-video), cropped/compressed by the author.
Sounds are synthesized in-browser. All code is original.

## Visual system (original to Kiki)
Yarn balls with tails, glowing loose threads, tiny thread knots, cross-stitch marks, knit "V" stitch texture, stitched (dashed) outlines,
and faceted **fallen-star fragments** instead of classic five-point stars or crescent moons. The constellation puzzle stitches an asymmetric
"Sky Needle". The cursor trail and confetti are thread snippets, knots and shards. Night mode uses a candle/tea toggle, not a moon.
